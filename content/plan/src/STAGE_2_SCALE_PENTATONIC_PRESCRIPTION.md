## Pattern 命名規則

`Pattern 1／2／3`、`A／B／C 指型` 都不是跨頻道通用標準：

- 成田系列的 A／B／C 是「跨弦音符數量＋撥片方向」單元，不是五聲音階的三個指板位置。
- YSOLIFE 的 Pattern 3 是該課程自己的 minor-pentatonic 位置命名。
- 金賢講兩支核心片應以音程公式、根音位置與大小調聲響識別，不替它們強加另一頻道的 Pattern 編號。

專案往後記錄指型時，至少寫成：

`來源系統｜音階種類｜主音｜音程公式｜根音所在弦／格｜影片原始名稱`

例如：

`金賢講｜A minor pentatonic｜A｜R-♭3-4-5-♭7｜依影片根音標示｜未使用 Pattern 編號`

4. `4Rdbm3bMJW4`：進入初學即興應用；畫面已確認涵蓋音程／調性、指型與簡單即興，作 Stage 2 出口。

`JE2uxXxOzVw` 不接在第 2 支後冒充「第三個位置」，而是在 Stage 3 以完整來源名稱標記：`YSOLIFE minor pentatonic Pattern 3／John Mayer application`。

## 四週進程

### 第 1 週：小調五聲音階與根音

- 使用 `96Loqj3NdeI`，只練一個位置。
- 每次上行／下行都在 root 停止並唱出或說出「根音」。
- 能說出公式 `R–♭3–4–5–♭7`，不只背格子。

### 第 2 週：小調短句

- 每句限制 3 個音，句尾回到 root 或另一個刻意選定的 chord tone。
- 保留空拍，禁止整段只上下跑完整音階。
- 錄製兩小節問句與兩小節答句。

### 第 3 週：大調五聲音階

- 使用 `p9abHX7tvq0` 的 `0:58–4:57`，先不加入 blue note。
- 說出公式 `R–2–3–5–6`，並標記 root。
- 在同一主音下比較 major 與 minor 聲響，不用 Pattern 編號比較。

### 第 4 週：大小調對照與概念整合

- 同一 backing context 中只選 major 或 minor，一次不混兩套。
- 用 `eYFN9BxBKMU` 回答：scale 是哪些音、shape 是它在指板上的排列、音樂應用需要哪些和弦／調性資訊。
- 若前三週穩定，可選看 `p9abHX7tvq0` 的 blue note／即興後段。

## 每日 20 分鐘處方

| 時間 | 內容 |
|---:|---|
| 3 分鐘 | 找出當天指型內所有 root，逐一彈並說出名稱 |
| 4 分鐘 | 慢速上行／下行一次，檢查音準、雜音與固定 down／up |
| 5 分鐘 | 限制 3 個音造短句，保留空拍 |
| 5 分鐘 | 對 backing track 演奏 2 小節問句＋2 小節答句 |
| 3 分鐘 | 記錄使用的是 major／minor、root、公式及唯一主要問題 |

Stage 2 維持 alternate picking；不在同一練習中加入四集系列的 economy-picking 撥向。

## 完成標準

- 能指出所學 minor 與 major 位置中的 root notes。
- 能說出兩套公式，並聽辨同主音 major／minor pentatonic 的聲響差異。
- 能演奏有休止、重複與句尾的短句，而不是只上下跑音階。
- 能說明「Pattern 3」是來源系統內的名稱，不能直接視為任何其他影片的第三個位置。
- 進 Stage 3 前，alternate picking 的跨弦必須穩定；economy-picking 不列為 Stage 2 畢業條件。
