# Stage 3｜3D Pentatonic 區域連接與和弦追蹤處方

## 核心結論

- `HAubjPmq4Is` → `wuAYAMQnu0g` 採用為 3D 核心上下集：先小調、後大調，兩集都以 Pattern 3 為家，向高音借 Pattern 4、向低音借 Pattern 2。
- `8uc9PqBaFC0` 作五位置地圖橋接。它用 A minor pentatonic 公式與五個指型建立全指板概念，但不把它的 Pattern 編號加入正式測驗，避免和 YSOLIFE 系列的編號系統混淆。
- `1vuv8gF8rw0` 作 3D capstone：先辨認整段維持同一調性的 horizontal playing，再練隨和弦切換 pentatonic 的 vertical playing，最後在兩者之間取得音樂性的平衡。
- `vxzLWz6P_Sw` 維持三形狀 reference，不另立一套必背編號。

## 最短核心路徑

1. 完成 Stage 2 的一個 minor pentatonic 與一個 major pentatonic 位置，能指出 root。
2. 快速觀看 `8uc9PqBaFC0`，理解五位置是重疊地圖；不要求一次背完五個 shape。
3. `HAubjPmq4Is`：建立小調 2／3／4 斜向路徑。
4. `wuAYAMQnu0g`：用同一路徑建立大調版本。
5. `1vuv8gF8rw0`：在和弦進行中比較「全段同一 pentatonic」與「逐和弦切換 pentatonic」，並錄音選擇兩者比例。

## 四週進程

### 第 1 週｜地圖與小調路徑

- 用 `8uc9PqBaFC0` 確認 A minor pentatonic 的 `1–♭3–4–5–♭7` 與五位置重疊概念。
- 進入 `HAubjPmq4Is`，以 C♯ minor Pattern 3 為家。
- 高音只借 Pattern 4 的 1–3 弦，低音只借 Pattern 2 的 5–6 弦，每次都回到 Pattern 3。

### 第 2 週｜斜向連接與轉調

- 練習影片的五音重複與滑音路徑，能說出 `♭7–1–♭3–4–5`。
- 把同一短句搬到低八度／高八度，保留相同節奏輪廓。
- 從 C♯ minor 轉到 A minor，再自選第三個小調；先找第六弦 root，再定位 Pattern 3。

### 第 3 週｜大調版本

- 依序使用 `wuAYAMQnu0g`，理解小調與大調可用同一幾何，但 root 對齊的手指不同。
- 以 E major 練 Pattern 3 → 借 Pattern 4 → 回家 → 借 Pattern 2。
- 把 2nd 滑入 major 3rd；雙音與較長 John Mayer 風格 lick 只作選修，不影響通過。
- 將路徑移調到 B major 或另一個熟悉的大調。

### 第 4 週｜Horizontal／Vertical 合流

- 使用 `1vuv8gF8rw0` 的 C♯ minor 語境，先整段只用 C♯ minor pentatonic，建立 horizontal 基準。
- 再依 C♯m、A、E、B 切換對應 major／minor pentatonic，聽出和弦輪廓；先限制在熟悉位置，不追求全指板。
- 最後錄三版：全 horizontal、全 vertical、混合版。若全 vertical 聽起來像機械換 pattern，減少切換頻率並保留共同音。

## 每日 24 分鐘處方

| 時間 | 任務 | 驗收點 |
|---:|---|---|
| 3 分 | 找 root 與 Pattern 3 | 指定調後能在第六弦定位，說明是食指或小指對齊 |
| 6 分 | 小調 2／3／4 斜向路徑 | 能指出何時借 2、何時借 4，最後回到家 |
| 5 分 | 大調同構路徑 | 不把 minor root 誤認為 major root；滑入 major 3rd 音準清楚 |
| 6 分 | 兩和弦再到四和弦即興 | 先 horizontal，再只在指定和弦做一次 vertical 切換 |
| 4 分 | 錄音與標記 | 記錄迷路、root 不明、節拍中斷或切換過度中的一項 |

若連續兩天在 Pattern 編號上混淆，暫停新 shape，只用「家／高音鄰區／低音鄰區」描述並練兩條弦。

## 完成標準

1. 能解釋五個位置是同一組五音的重疊區域，而不是五套不同音階。
2. 在至少三個小調定位 Pattern 3，完成向 Pattern 2／4 借音的斜向路徑，仍能指出 root。
3. 在至少兩個大調完成同一路徑，並說明小調以食指、大調以小指對齊影片所用 Pattern 3 root 的差異。
4. 能把一個 2–4 拍 motif 搬到另一個八度，而不是只上下跑完整音階。
5. 能用自己的話說明 horizontal 與 vertical improvising，並在至少一個四和弦進行各示範一次。
6. 混合版錄音維持 8–16 小節節拍，換和弦時能指出保留的共同音或切換後強調的和弦音。

速度、完整五 shape 背誦、雙音與跨兩個半八度的長 lick 都不是 3D 的必要畢業條件。
