# Stage 2 節奏、基礎樂理與單一指型

## Stage 2 出口能力

完成後應能：

- 使用 slide、octave 或 harmonic 等基本 articulation，但不以速度為目標。
- 彈奏開放／barre chords、基本節奏型與一個完整和弦進行。
- 理解音名、音程、大調音階、triad／基本和弦公式與調性概念。
- 彈 minor／major pentatonic 的核心單一指型並知道根音。
- 在簡單 backing track 中完成短句或入門即興。

## 模組完成標準

### 和弦與節奏

- 在不停止拍點的情況下完成一個開放／barre chord 進行。
- 能演奏 straight 與至少一種 syncopated pattern。
- 能以單音或分解和弦方式重新表達同一進行。

### 基礎樂理

- 能說明 root、3rd、5th 與 major／minor triad 差異。
- 能從一個調找到主要和弦，而不是只背形狀。
- 能說明五度圈在轉調／和弦關係上的用途。

### 音階與 Pentatonic

- 能指出所彈指型的 root notes。
- 能分辨 major 與 minor pentatonic 的音程／聲響差異。
- 能在慢速 backing track 中演奏短句，而不是只上下跑音階。

## Stage 2 結尾：Jazz 入門橋接（選修）

2026-10-26 新增。目的：在 Stage 2 結尾先建立 Jazz 和聲的最小手感，讓 Jazz 優先的路線不必等到 Stage 4 才第一次接觸 7th chord。這是輕量橋接，不列入 Stage 2 畢業門檻，也不取代 Stage 4 的 Jazz 路線。

**進入條件**：已能完成 barre chord 與兩個和弦間不停拍切換（A 模組），並看過 `kMZ665uoZDo` 的順階和弦。

**每日約 4 分鐘**（放在 Stage 2 每日處方最後，不另外加長總時數；可從當天和弦／節奏處方的錄音段挪用）。

### 1｜Shell voicings（只彈三個音：R、3、7）

- 根音在第 6 弦：`R–7–3`（第 6、4、3 弦），第 5、2、1 弦悶掉。
- 根音在第 5 弦：`R–3–7`（第 5、4、3 弦），第 6、2、1 弦悶掉。
- 先學三種和弦性質：maj7、m7、7（dominant）。只差 3rd 或 7th 一個音。

### 2｜ii–V–I 三個調（指板記法：第 6 弦 → 第 1 弦）

| 調 | ii | V | I |
|---|---|---|---|
| C | Dm7 `x 5 3 5 x x` | G7 `3 x 3 4 x x` | Cmaj7 `x 3 2 4 x x` |
| F | Gm7 `3 x 3 3 x x` | C7 `x 3 2 3 x x` | Fmaj7 `1 x 2 2 x x` |
| B♭ | Cm7 `x 3 1 3 x x` | F7 `1 x 1 2 x x` | B♭maj7 `x 1 0 2 x x` |

**Guide tones（以 C 調為例）**：第 4 弦 F → F → E、第 3 弦 C → B → B。每次換和弦只有一個音移動半音，左手應該幾乎不動；先只彈這兩條弦聽 3rd／7th 的走向，再加回根音。

### 3｜Comping 節奏

- 4/4、swing feel，60–80 BPM，節拍器只響在 2、4 拍。
- 每小節在 2、4 拍各刷一次短音（右手刷完立刻用左手放鬆悶音），每個和弦 1 小節，I 和弦停 2 小節。

### 完成標準（選修）

- C、F、B♭ 三個調的 ii–V–I 各能以 swing 2、4 拍 comping 連續 8 小節不停拍。
- 任意指出一個 shell voicing 中哪個音是 3rd、哪個是 7th。
- 練習紀錄用一行寫下調與和弦、做什麼、BPM、次數、乾淨程度，以及哪一顆音沒按響。例如 `Jazz ii–V–I｜C／F｜comping 2&4｜70｜4｜2｜B♭maj7 第 3 弦按不響`。
