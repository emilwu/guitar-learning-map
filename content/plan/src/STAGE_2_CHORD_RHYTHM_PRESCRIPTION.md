# Stage 2 和弦／節奏主線與練習處方

## 結論

原六支主線涵蓋範圍正確，但角色與順序需要調整：`T3J5PmNws7g` 是回顧多種節奏技巧的綜合演奏曲，應放在最後；`Rn_BY3jp2mQ` 與封閉和弦核心課重疊，改為卡關診斷；`NDIxitdkzVI` 依賴順階和弦與級數，移到 Stage 2 樂理鏈之後。

最短完整主線保留五支：

`LnWPZWJMa00` → `jWSTYN8MOVI` → `ZcxgfJaQObc` → `CFz1959htgM` → `T3J5PmNws7g`

## 播放順序

### 和弦／節奏區塊

1. `LnWPZWJMa00`：把已會的基本和弦轉成電吉他／Rock 語彙。
2. `jWSTYN8MOVI`：建立可移動的封閉和弦方法。
3. `Rn_BY3jp2mQ`：僅在封閉和弦卡關時插入。
4. `ZcxgfJaQObc`：以分解和弦練逐弦控制與固定 pattern。
5. `CFz1959htgM`：在穩定八分音符上加入切分。
6. `T3J5PmNws7g`：整合 power chord、open chord、palm mute 與節奏切換。

### 樂理後應用

`FVvGt_raeFA` → `LtmUy1gUIaU` 指定章節 → `kMZ665uoZDo` → `NDIxitdkzVI`

`NDIxitdkzVI` 不阻擋完成 Stage 2 和弦／節奏模組，但可作為「理解級數後能否用耳朵落地」的驗收。

## 五週進程

### 第 1 週：開放和弦與不中斷拍點

- 使用 `LnWPZWJMa00` 的和弦形狀與進行。
- 先以全音符／二分音符換和弦，再加入固定八分音符。
- 換和弦時右手維持拍點；允許左手早期只換兩個和弦。

### 第 2 週：封閉和弦

- 使用 `jWSTYN8MOVI`，先單獨檢查食指 barre，再加入其餘手指。
- 一次只練一個形狀和兩個位置，不連續大範圍滑動。
- 若兩次練習仍無法得到乾淨聲音，才插入 `Rn_BY3jp2mQ` 做診斷。

### 第 3 週：分解和弦

- 使用 `ZcxgfJaQObc`，先選一種 pattern。
- 左手保持同一進行，右手固定弦序；錯一個音時只修該次跨弦。
- 能連續 8 小節後才加入第二種手法。

### 第 4 週：切分音

- 使用 `CFz1959htgM`，先離開吉他拍手並數 subdivision。
- 接著以單一悶音和弦演奏節奏，再換成影片歌曲／和弦範例。
- 能明確指出重音落在哪個拍點或拍間位置，才算理解，不只靠模仿。

### 第 5 週：綜合節奏曲

- 使用 `T3J5PmNws7g`，先拆成 power chord、palm mute、open chord 三段。
- 各段能穩定 4 小節後再串接。
- 以低於示範的速度完成整段，速度不是畢業條件。

## 每日 24 分鐘處方

| 時間 | 內容 |
|---:|---|
| 3 分鐘 | 逐弦檢查當週和弦，找出悶音／多餘共振 |
| 5 分鐘 | 兩個和弦之間慢速切換，右手保持拍點 |
| 5 分鐘 | 當週節奏：固定八分、分解 pattern 或切分音，只選一項 |
| 6 分鐘 | 當週主影片的短段落，最多 4–8 小節 |
| 5 分鐘 | 不停拍演奏一個循環並錄音；最後記錄唯一主要錯誤 |

## 完成標準

- 開放／封閉和弦進行可連續 8 小節，不因換和弦停止右手拍點。
- 能用刷奏與分解和弦兩種方式表達同一進行。
- 能先拍手再彈出至少一個切分節奏，並說明重音位置。
- 可在降低速度後完成 `T3J5PmNws7g` 的分段串接，雜音與節拍可控。
- 選修驗收：學完順階和弦後，可用 `NDIxitdkzVI` 的級數方法找出簡單進行。

## 安全與證據限制

- 封閉和弦以角度、手臂自然重量與琴況診斷優先，不以最大握力硬壓；尖銳疼痛或麻木立即停止。
- `LnWPZWJMa00` 是 Rock 開放和弦應用，不足以單獨補齊完全沒學過的所有開放和弦；本路徑假設已通過 Stage 1 的簡單和弦循環。
- 本輪使用影片說明、章節、既有字幕證據與輕量畫面；雖確認六支有繁中人工字幕軌，但因字幕端點封鎖未重新抓取逐句內容。
