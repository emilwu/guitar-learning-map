Stage 2 出口能力

完成後應能：

  • 使用 slide、octave 或 harmonic 等基本 articulation，但不以速度為目標。
  • 彈奏開放／barre chords、基本節奏型與一個完整和弦進行。
  • 理解音名、音程、大調音階、triad／基本和弦公式與調性概念。
  • 彈 minor／major pentatonic 的核心單一指型並知道根音。
  • 在簡單 backing track 中完成短句或入門即興。

模組完成標準

和弦與節奏

  • 在不停止拍點的情況下完成一個開放／barre chord 進行。
  • 能演奏 straight 與至少一種 syncopated pattern。
  • 能以單音或分解和弦方式重新表達同一進行。

基礎樂理

  • 能說明 root、3rd、5th 與 major／minor triad 差異。
  • 能從一個調找到主要和弦，而不是只背形狀。
  • 能說明五度圈在轉調／和弦關係上的用途。

音階與 Pentatonic

  • 能指出所彈指型的 root notes。
  • 能分辨 major 與 minor pentatonic 的音程／聲響差異。
  • 能在慢速 backing track 中演奏短句，而不是只上下跑音階。

Stage 2 結尾：Jazz 入門橋接（選修）

2026-10-26 新增。目的：在 Stage 2 結尾先建立 Jazz 和聲的最小手感，讓 Jazz 優先的路線不必等到 Stage 4 才第一次接觸 7th chord。這是輕量橋接，不列入 Stage 2 畢業門檻，也不取代 Stage 4 的 Jazz 路線。

進入條件：已能完成 barre chord 與兩個和弦間不停拍切換（A 模組），並看過 kMZ665uoZDo 的順階和弦。

每日約 4 分鐘（放在 Stage 2 每日處方最後，不另外加長總時數；可從當天和弦／節奏處方的錄音段挪用）。

1｜Shell voicings（只彈三個音：R、3、7）

  • 根音在第 6 弦：R–7–3（第 6、4、3 弦），第 5、2、1 弦悶掉。
  • 根音在第 5 弦：R–3–7（第 5、4、3 弦），第 6、2、1 弦悶掉。
  • 先學三種和弦性質：maj7、m7、7（dominant）。只差 3rd 或 7th 一個音。

2｜ii–V–I 三個調（指板記法：第 6 弦 → 第 1 弦）

調iiVI
CDm7 x 5 3 5 x xG7 3 x 3 4 x xCmaj7 x 3 2 4 x x
FGm7 3 x 3 3 x xC7 x 3 2 3 x xFmaj7 1 x 2 2 x x
B♭Cm7 x 3 1 3 x xF7 1 x 1 2 x xB♭maj7 x 1 0 2 x x

Guide tones（以 C 調為例）：第 4 弦 F → F → E、第 3 弦 C → B → B。每次換和弦只有一個音移動半音，左手應該幾乎不動；先只彈這兩條弦聽 3rd／7th 的走向，再加回根音。

3｜Comping 節奏

  • 4/4、swing feel，60–80 BPM，節拍器只響在 2、4 拍。
  • 每小節在 2、4 拍各刷一次短音（右手刷完立刻用左手放鬆悶音），每個和弦 1 小節，I 和弦停 2 小節。

完成標準（選修）

  • C、F、B♭ 三個調的 ii–V–I 各能以 swing 2、4 拍 comping 連續 8 小節不停拍。
  • 任意指出一個 shell voicing 中哪個音是 3rd、哪個是 7th。
  • 練習紀錄用一行寫下調與和弦、做什麼、BPM、次數、乾淨程度，以及哪一顆音沒按響。例如 Jazz ii–V–I｜C／F｜comping 2&4｜70｜4｜2｜B♭maj7 第 3 弦按不響。

之後的銜接

  • Stage 3：延伸到 drop-2 voicings、walking bass 片段與 guide-tone 單音線。
  • Stage 4：進入正式 Jazz 路線（Stage 4 課程）。本節沒有綁定影片；Jazz 影片仍以 Stage 4 播放清單為準。

第 1 週：開放和弦與不中斷拍點

第 2 週：封閉和弦

第 4 週：切分音

  • 能明確指出重音落在哪個拍點或拍間位置，才算理解，不只靠模仿。

完成標準

  • 開放／封閉和弦進行可連續 8 小節，不因換和弦停止右手拍點。
  • 能用刷奏與分解和弦兩種方式表達同一進行。

安全

  • 封閉和弦以角度、手臂自然重量與琴況診斷優先，不以最大握力硬壓；尖銳疼痛或麻木立即停止。

Pattern 命名規則

Pattern 1／2／3、A／B／C 指型 都不是跨頻道通用標準：

  • 成田系列的 A／B／C 是「跨弦音符數量＋撥片方向」單元，不是五聲音階的三個指板位置。
  • YSOLIFE 的 Pattern 3 是該課程自己的 minor-pentatonic 位置命名。
  • 金賢講兩支核心片應以音程公式、根音位置與大小調聲響識別，不替它們強加另一頻道的 Pattern 編號。

專案往後記錄指型時，至少寫成：

來源系統｜音階種類｜主音｜音程公式｜根音所在弦／格｜影片原始名稱

例如：

金賢講｜A minor pentatonic｜A｜R-♭3-4-5-♭7｜依影片根音標示｜未使用 Pattern 編號

四週進程

第 1 週：小調五聲音階與根音

  • 使用 96Loqj3NdeI，只練一個位置。
  • 每次上行／下行都在 root 停止並唱出或說出「根音」。
  • 能說出公式 R–♭3–4–5–♭7，不只背格子。

第 2 週：小調短句

  • 每句限制 3 個音，句尾回到 root 或另一個刻意選定的 chord tone。
  • 保留空拍，禁止整段只上下跑完整音階。
  • 錄製兩小節問句與兩小節答句。

第 3 週：大調五聲音階

  • 使用 p9abHX7tvq0 的 0:58–4:57，先不加入 blue note。
  • 說出公式 R–2–3–5–6，並標記 root。
  • 在同一主音下比較 major 與 minor 聲響，不用 Pattern 編號比較。

第 4 週：大小調對照與概念整合

  • 同一 backing context 中只選 major 或 minor，一次不混兩套。
  • 用 eYFN9BxBKMU 回答：scale 是哪些音、shape 是它在指板上的排列、音樂應用需要哪些和弦／調性資訊。
  • 若前三週穩定，可選看 p9abHX7tvq0 的 blue note／即興後段。

每日 20 分鐘處方

時間內容
3 分鐘找出當天指型內所有 root，逐一彈並說出名稱
4 分鐘慢速上行／下行一次，檢查音準、雜音與固定 down／up
5 分鐘限制 3 個音造短句，保留空拍
5 分鐘對 backing track 演奏 2 小節問句＋2 小節答句
3 分鐘記錄使用的是 major／minor、root、公式及唯一主要問題

Stage 2 維持 alternate picking；不在同一練習中加入四集系列的 economy-picking 撥向。

完成標準

  • 能指出所學 minor 與 major 位置中的 root notes。
  • 能說出兩套公式，並聽辨同主音 major／minor pentatonic 的聲響差異。
  • 能演奏有休止、重複與句尾的短句，而不是只上下跑音階。
  • 能說明「Pattern 3」是來源系統內的名稱，不能直接視為任何其他影片的第三個位置。
  • 進 Stage 3 前，alternate picking 的跨弦必須穩定；economy-picking 不列為 Stage 2 畢業條件。
