這份計劃把 Stage 1–4 收成一條可以走完的路。學習地圖、每週任務、影片與練習工具都在這個網站裡接起來，不用在好幾個地方自己拼。

這個網站怎麼帶你走

每週只做一個主目標，頁面裡按順序走三步，階段最後才看出口：

  1. 學習方式：這一週在學什麼、怎麼練。需要時展開計畫摘錄；完整原文在同一站的階段頁。
  2. 看影片：當週播放清單的指定影片。看完回到這一頁，再進練習。
  3. 練習：練習工具直接嵌在這一頁。和弦、三和弦、pentatonic 用和弦探索器；需要穩拍時用節拍器。做完在同一頁勾選，或到下一步。
  4. Stage 出口：該階段的週次走完後，用能力閘門檢查。勾的是「做得到」，不是「看過」。

頁首的進度與「繼續」會回到上次停下的階段、週次與步驟。進度只存在這台裝置的瀏覽器。

要同時成立的兩件事

  1. 單靠 YouTube 也能學：播放清單裡的順序就是課程，不看網站也能往下走。
  2. 網站負責讓你少迷路：它補上為什麼現在看這支、練完要證明什麼、卡住要回哪裡。網站不是第二套教材。

先備不能倒著走

Stage 0 是把琴調好、找到不會痛的姿勢、讓每天的練習有固定結構。這個網站的主線從 Stage 1 開始。

階段你在建立什麼過了才算
Stage 1左右手基本控制、止音、交替撥弦、第一個短循環8 小節和弦或 power chord 不中斷，聲音與身體大致放鬆
Stage 2開放／封閉和弦、分解與切分、基礎和聲、一個位置的 pentatonic同一進行能刷也能分解；短句有 root、休止與句尾
Stage 3指板地標、triad、chord tone、把位連接、句法與通用 rhythm兩個相鄰區域仍找得到 root，並錄下 16 小節 rhythm 與 lead
Stage 4七和弦、Drop 2、依和弦選音、chord-melody，再選一條曲風8–16 小節 chord-melody，加上 Jazz、Blues 或 Neo-Soul 其中一條專修
Stage 5曲風語彙與完整曲目不在這個網站的主線裡；曲目用來驗收，不取代前面的能力

支線（modes、Funk、高速技巧、曲風專修）只在主線穩了之後開。補強是處理已經看到的缺口，不是額外必修。

怎麼練才不會白看

  • 概念先於使用它的練習；慢、單一變因先於把很多技巧疊在一起。
  • 一次只改一個變因：弦組、速度、把位或和弦數。
  • 每週留下聽得見的證據：錄音、錄影、口述或一張和聲表。「感覺有進步」不能代替。
  • 沒通過就只補最低的那一項，縮小範圍，不從頭重看整套影片。
  • 尖銳疼痛、麻木或持續刺痛立刻停。封閉和弦用角度與手臂重量，不用最大握力硬壓。
  • 速度只有在連續兩次大約九成乾淨、拍點穩定、身體沒有明顯僵硬時才加 2–4 BPM。

練習工具放在哪

和弦探索器嵌在第 3 步裡，並會打開處方寫到的和弦或音階。節拍器也嵌在同一頁：處方寫了速度或拍點時，連結會帶上那個預設，例如 60 BPM 的四分或八分，或 Jazz 只響在第 2、4 拍。指板訓練仍在做。沒有合適工具的週次，就直接在琴上做。

吉他學習先備地圖 V0

用途與邊界

本文件先定義能力順序，不直接宣稱某支影片已是最佳教材。個別影片仍需 difficulty、prerequisites、transcript 與 visual evidence。

器材 E 不放入同一條吉他核心主線，而在需要時支援各階段。Bass 已由使用者指定延後另案整理，目前只保留隔離分類。

核心先備關係

能力先後可以看成：練習系統與安全姿勢，接著左右手控制、拍點和基本和弦，再到音程、triad、pentatonic、把位連接與 chord tone，最後才是曲風和曲目。每週實際順序以階段頁和學習地圖上的流程為準。

階段定義

Stage 0｜建立可持續的練習環境

  • 調音、坐／站姿、基本放鬆與器材安全
  • 每日練習結構、節拍器與錯誤紀錄
  • 完成標準：能在不疼痛、不過度用力的情況下完成短練習

Stage 1｜動作與時間感

  • 左右手基本控制、換弦、簡單 muting
  • 四分、八分、十六分與三連音的拍點
  • 基本開放和弦、power chord 或單音 riff
  • 完成標準：能在固定 BPM 連續演奏並保持乾淨

Stage 2｜指板與和聲基礎

  • 音名、音程、大調音階與調性
  • triad／基本和弦公式
  • minor／major pentatonic 的單一核心指型
  • 完成標準：知道所彈的根音、音階／和弦功能，而不是只背格數

Stage 3｜導航、伴奏與音樂化

  • CAGED 或選定的一套指板導航法
  • 和弦進行、groove、分解和弦與節奏變化
  • pentatonic 把位連接、bend、slide、vibrato 與 motif
  • 完成標準：能在 backing track 中維持節奏並產生短而完整的樂句

Stage 4｜依和弦選音與完整即興

  • arpeggios、chord tones、triads 與 voice leading
  • call-and-response、空間、發展與段落結構
  • jam session 與完整 solo
  • 完成標準：能說明關鍵選音與和弦的關係，並錄下可重複評估的演奏

Stage 5｜曲風與曲目整合

  • 依 Blues、Rock、Funk、Jazz、Neo-Soul 等路線補充語彙
  • 完整歌曲、riff、solo、伴奏與編曲
  • 完成標準：完成可演出或錄製的曲目，並能把其中技巧移植到新情境

Stage 3 展開

Stage 3 不採「看完所有 C3 再進 C4」的線性方式，而拆成指板地標／triads 的共同基礎，再讓 arpeggio／chord-tone 與 pentatonic／phrasing 並行，最後在和弦落點即興合流。進階 rhythm 與曲風作分支，modes 延後選修，速度與 economy picking 作需求式技術支援。

完整模組、出口能力與第一批核心候選見 Stage 3 架構。

曲風與曲目如何接入

  • 曲風 S 不是 Stage 0 的替代品；每條曲風都要明列 C1–C4 先備。
  • 曲目 R 可在早期作動機與小型驗收，但完整版本應放在相關能力之後。
  • 同一支曲目影片可以引用多個能力模組，但只在全域主檔維護一次。
  • backing track 可同時是 C2 節奏任務與 C4 即興任務，網站應提供不同練習指令。

影片排序規則

  1. 概念定義排在要求使用該概念的練習之前。
  2. 慢速、單一變因排在多技巧整合與速度挑戰之前。
  3. 單一把位排在全指板與多系統比較之前。
  4. rhythm／time 基礎不能被 solo 興趣支線完全跳過。
  5. 純展示、Shorts 與 inspiration 不可成為唯一核心教材。
  6. 多套互斥系統只選一套作主線，其餘標為 alternative／reference。
  7. 每個模組以可觀察的 completion check 結束，再進入下一節點。
