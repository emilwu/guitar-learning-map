# Guitar Learning Map

## 網站內容

從基本動作、節奏與 Pentatonic，到指板導航、進階和聲與編曲的四階段吉他課程。網站包含 49 個主線週次、十六個 YouTube Playlist、每日練習配置、週末通過證據與能力閘門。

## 使用方式

先用首頁的程度判斷找到入口；一次只進行一個 Stage 與一個週任務。影片看完不代表完成，必須留下該週要求的錄音、錄影、口述或書面證據。

## 隱私

學習進度只保存在瀏覽器 localStorage。網站沒有帳號、追蹤、上傳或伺服器資料庫。YouTube Playlist 目前為私人，只有具權限的頻道帳號能播放。
